# SilverHands: Trusted Skills, Beautifully Connected

Create a modern, luxury, minimalist, responsive web application called "SilverHands" – an AI-powered marketplace connecting senior citizens and homemakers with customers.

Design Style:

- Luxury minimalistic aesthetic

- Clean layouts with generous whitespace

- Soft rounded corners

- Elegant typography

- Professional yet warm and welcoming

- Mobile-first responsive design

- Accessible UI with large touch targets and clear navigation

- Senior-friendly readability

Color Palette:

Primary: #6B7A3E (Olive Green)

Secondary: #FFFDF5 (Ivory)

Accent: #C98C3A (Warm Gold)

Text: #2F312B (Dark Olive Gray)

Use the primary color for buttons, navigation highlights, and important actions.

Use the accent color for CTAs, badges, and premium highlights.

Use the secondary color as the main background.

Use the text color for all primary content.

Landing Experience:

When users enter the platform, present a beautiful onboarding screen with:

Headline:

"Turn Skills Into Opportunities"

Subheadline:

"Empowering senior citizens and homemakers through AI-powered livelihood opportunities."

Two large cards:

1. Buyer

Icon: Shopping bag

Description:

"Discover trusted local services, handmade products, mentors, and experts."

Button:

"Continue as Buyer"

2. Seller

Icon: Briefcase or Storefront

Description:

"Offer your skills, products, knowledge, and services to customers."

Button:

"Continue as Seller"

The cards should be large, elegant, and easy to select.
